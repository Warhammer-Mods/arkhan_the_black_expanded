The user requested a full source replacement from their named current pack, preserving additions and removals rather than merging older versions back in.

- Input pack: `arkhan_the_black_expanded.pack`, SHA-256 `2cf48507769cbc750095495ae488c69289555da2cff31e5785a015256c60f0fd`.
- Input inventory: 746 game files, plus three RPFM editor entries.

- Final pack: SHA-256 `d5a3efa06653f64320a2440ee60b3789027683667ec400b9aaf0051b884b18e8`; 751 game files, plus the same editor entries.
- Adopted source inventory: `docs/main_pack_baseline.json`.

The root pack matched the ZIP supplied earlier on the same day. The repository had not yet adopted that full pack as its replacement basis; applying only a narrow fix to the old repository left obsolete game entries available to later builds. This adoption replaces all main game sources and removes those leftovers. Repository tooling, documentation, and separate submods remain outside the replacement.

All 219 adopted DB exports were decoded against their actual schema versions and verified by native re-encoding, including a second check through the generated TSV values. The two DB fragments with ColourRGB fields were retained as native binaries; their bytes were not approximated or rewritten. All 36 LOC resources were decoded/round-trip checked and retained as native binaries, preserving flags, text and newline semantics.
